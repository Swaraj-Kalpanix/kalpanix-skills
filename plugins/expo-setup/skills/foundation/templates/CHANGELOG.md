## [Unreleased]

### Added
- Project structure for AI-assisted development: `AGENTS.md` (agent rules), `CLAUDE.md` (project context), `CHANGELOG.md`, `docs/` (plans, memos, modules, TODO board), and project skills in `.claude/skills/` (`plan-feature`, `new-module`, `wrap-up`). (PLAN-001, MEMO-001)
- Feature-based folder structure defined in `AGENTS.md`: each feature in `src/features/<feature>/` owns its screens, components, hooks, services, queries, schemas and types; shared code lives in root `src/` folders. Folders are created on demand. (PLAN-001)
- Naming conventions in `AGENTS.md`: PascalCase component files, `useX` hook files, `<name>.service.ts` / `.schema.ts` / `.types.ts` / `.queries.ts` / `.mock.ts` role suffixes, no kebab-case outside `src/app` routes. (PLAN-001)
- ESLint (`eslint.config.js`, `eslint-config-expo`), generated by `npx expo lint`. (PLAN-001)

### Changed
- App identity: display name "{{APP_NAME}}", iOS bundle identifier and Android package `{{BUNDLE_ID}}`, scheme `{{SCHEME}}`; removed the `web` section from `app.json` (mobile-only app). (PLAN-001)

### Removed
- Expo starter template: demo screens and tabs, template components, hooks, constants, `global.css`, demo images, and the `reset-project` script. `src/app` keeps only a root layout and a placeholder home route. (PLAN-001)
